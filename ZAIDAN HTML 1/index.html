A Identitas Pembelajaran

  • Mata Pelajaran: Dasar-Dasar Pengembangan Perangkat Lunak dan Gim
  • Materi: Variable pada JavaScript
  • Model Pembelajaran: Problem Based Learning / Discovery Learning
  • Metode: Eksplorasi, praktik, diskusi, tanya jawab, refleksi

B Tujuan Pembelajaran

Setelah menyelesaikan kegiatan pembelajaran ini, peserta didik diharapkan mampu:

  1. Menjelaskan pengertian variable dengan bahasa sendiri.
  2. Menjelaskan fungsi variable dalam program.
  3. Membedakan let dan const secara sederhana.
  4. Membuat variable menggunakan JavaScript.
  5. Memberikan nama variable sesuai aturan penamaan.
  6. Menyimpan data berupa teks dan angka ke dalam variable.
  7. Menampilkan nilai variable menggunakan console.log()
  8. Membuat program JavaScript sederhana yang menggunakan beberapa variable.
  9. Menemukan dan memperbaiki kesalahan sederhana pada penggunaan variable.

C Petunjuk Keselamatan dan Kerja

Dalam kegiatan praktik:

  • Gunakan komputer/laptop dengan hati-hati. Jangan menghapus file milik teman.
  • Simpan pekerjaan secara berkala. Jangan menyalin kode teman tanpa memahami fungsinya.
  • Jika menemukan error, jangan panik. Baca pesan error dan diskusikan penyebabnya.
  • Setiap anggota kelompok harus memahami hasil pekerjaan kelompok.

D Apersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui:

Nama siswa Kelas Umur Nilai Jurusan
Nama siswa = "Budi"
Kelas = "XI RPL 1"
Umur = 16
Nilai = 85

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program?

Tuliskan dugaanmu: Kita dapat menyimpannya menggunakan variable di JavaScript agar data dapat ditampung dan dipanggil kembali dengan mudah menggunakan perintah output seperti console.log().

E Aktivitas 1 - Mengamati

let nama = "Budi";
let umur = 16;
let nilai = 85;
console.log(nama);
console.log(umur);
console.log(nilai);

1. Apa yang ditampilkan pada Console?

Budi, 16, dan 85 (masing-masing di baris terpisah).

2. Menurutmu, apa fungsi nama, umur, dan nilai?

Berfungsi sebagai pengenal atau label penampung (variable) untuk menyimpan data teks maupun angka.

3. Apa yang terjadi jika kode berikut dijalankan? console.log(nama);

Jawaban: Program akan mencetak nilai yang tersimpan di dalam variable nama yaitu "Budi" ke console browser.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variable adalah wadah atau tempat penyimpanan data di dalam memori komputer agar dapat diproses atau ditampilkan kembali saat program berjalan.

G Aktivitas 3 - Praktik Membuat Variable

File: variable.html

<!DOCTYPE html>
<html>

    <title>Belajar Variable</title>

</html>

H Aktivitas 4 - Eksperimen

Mengubah nilai variable dengan data Zaidan (X PPLG 2):

let nama = "Zaidan";
let kelas = "X PPLG 2";
let umur = 16;
console.log(nama);
console.log(kelas);
console.log(umur);

1. Apakah hasil pada Console berubah?

Ya, hasil console berubah menampilkan "Zaidan", "X PPLG 2", dan "16".

2. Bagian kode mana yang kamu ubah?

Bagian nilai string di dalam tanda kutip pada variable nama dan kelas.

3. Mengapa program dapat menampilkan data yang baru?

Karena program mengeksekusi kode sesuai dengan nilai terbaru yang disimpan di dalam memori/variable tersebut.

J Aktivitas 6 - Mengenal let dan const

Pengujian keyword let dan const:

Keyword Nilai dapat diubah? Kegunaan Sederhana
letYaUntuk data yang nilainya masih mungkin berubah di kemudian hari.
constTidak (Tetap)Untuk data konstan yang tidak perlu diubah-ubah nilainya.

K Aktivitas 7 - Aturan Penamaan Variable

Diperbolehkan:

  • let nama;
  • let namaSiswa;
  • let nama_siswa;
  • let nilai1;

Tidak Diperbolehkan:

  • let 1nama; (Diawali angka)
  • let nama siswa; (Mengandung spasi)
  • let nama-siswa; (Mengandung tanda hubung/minus)
